# junimo

### Setup
1. Download repo
2. Install Python if you don't have it already - https://www.python.org/downloads/
3. Confirm python is installed `python3 --version`. You should see something like `Python 3.13.2` in your terminal
4. Navigate to repo in your terminal `cd path/to/folder`
5. Start local server in terminal `python3 -m http.server 8000`
6. Open browser window and go to `http://localhost:8000/index.html`
